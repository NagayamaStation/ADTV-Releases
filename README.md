# ADTV

A free railway desktop application for Windows 10 and 11 (64-bit).

## Download ADTV 1.2.4

Download [ADTV 1.2.4](https://github.com/NagayamaStation/ADTV-Releases/releases/tag/v1.2.4), extract the complete ZIP into a permanent writable folder, and run `DesktopYamanoteLine.exe` at the top level. Keep the `app` folder beside it.

Existing users: open **Settings > Updates > Check for updates**, then download and install the available update. Use the built-in updater to keep your installation location and preferences. If launching a separate extracted copy, first exit the old copy from its tray menu.

Version 1.2.4 improves desktop attachment and recovery. If the wallpaper does not appear, check **Settings > Appearance > Display** and use **Reconnect wallpaper**. **About > Copy troubleshooting information** provides a report to share with support.

Automatic updates check daily at 02:00 local time, or five minutes after app startup/resume when a check was missed. No account is required. Settings includes **Pause updates** and **Show new lines automatically**. The version is shown at the top right and in Settings.

This release continues the existing update-test connection and its preferences. To test updating from an older build, the [update test starter](https://github.com/NagayamaStation/ADTV-Releases/releases/tag/update-test-start) remains available.

ADTV is an offline simulation. Third-party licences and data attribution are included in `app/Notices` in each download.

This repository contains downloads and update metadata.
